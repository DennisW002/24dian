# 胖猪来24点

无需构建的 24 点网页游戏。直接打开 `index.html` 即可试玩；通过 HTTP 服务打开时支持离线缓存。

- 共 5 关，每关限时 5 分钟，答对得 1 分。
- 可暂停计时，暂停时题目会隐藏。
- 答错后可在剩余时间内重新作答，或直接进入下一关；超时后显示正确答案，不能重试。
- 结算页显示得分、总耗时和每关记录。

在线试玩：https://dennisw002.github.io/24dian/

## 双人在线 PK

双人版位于 `pk/`，需要一个运行 Node.js 的在线服务。房间由服务端创建并通过 WebSocket 实时同步；双方选择名字和 20 款头像之一，发起者分享房间链接，双方准备后由发起者开始。每盘从 404 道有解题中按 5 个难度档重新抽取题目。两人分别完成 5 关，最后显示得分、总耗时和 Winner；同分时总耗时更短者获胜，两项都相同才是平局。服务端判题和计时，超时显示正确答案。

先完成的玩家在等待页可发送“小猪路过”“星星闪闪”“调皮眨眼”三种全屏视觉干扰。每场最多 5 次，间隔至少 12 秒；动画不会接收点击，也不会改变对手计时、题目或分数。接收方可随时关闭干扰。

邀请朋友时，“微信邀请”会复制专属房间链接并显示发送步骤。玩家在微信聊天中粘贴链接即可邀请朋友；页面不依赖系统分享菜单中的微信转发动作。

创建房间的玩家离开页面后，在同一设备、同一浏览器重新打开原始游戏地址，会凭本机保存的身份自动回到房间。通过带房间号的邀请链接返回也可以。服务重启导致房间过期时需新建房间；更换设备或浏览器无法继承本机身份。

本地运行：

```bash
npm ci
npm start
```

打开 `http://localhost:3000/`。运行测试：`npm test`。

### 发布双人版

[通过 Render 部署](https://render.com/deploy?repo=https://github.com/DennisW002/24dian)。登录 Render 后确认仓库和 `render.yaml` 中的免费 Web Service 配置，部署完成后使用 Render 提供的 `https://…onrender.com/` 地址创建对战，并把该地址生成的邀请链接发给朋友。原 GitHub Pages 链接仍是单人版。

免费服务闲置后会休眠，首次打开可能需要等待。房间暂存在服务内存中，服务重启后未完成的房间会过期；适合朋友间试玩。

职业人物与动物头像使用 Twemoji SVG，来源和许可见 [头像素材说明](pk/ASSET-LICENSE.md)。
